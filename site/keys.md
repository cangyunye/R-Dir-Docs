# 快捷键速查

全部动作注册在同一张键位表上，统一逻辑键 `mod` = Windows **Ctrl** / macOS **⌘**。
所有键位都可在 **设置 → 快捷键**（`Ctrl+,`）里点「录制」自定义，带冲突检测与恢复默认；
随时按 **`F1`** 在应用内呼出同样的键位一览。按 `Ctrl+K` 呼出命令面板也可直达全部动作。

## 导航

| 动作 | Windows | macOS |
| --- | --- | --- |
| 上一级目录 | `Alt+↑` / `Backspace` | `⌘↑` / `Backspace` |
| 后退 | `Alt+←` | `⌘[` |
| 前进 | `Alt+→` | `⌘]` |
| 刷新 | `F5` | `⌘R` |
| 聚焦地址栏 | `Ctrl+L` | `⌘L` |
| 前往主目录 | `Ctrl+Shift+H` | `⌘⇧H` |

| 动作 | Windows | macOS |

::: tip
窗口缩放：`Ctrl+滚轮`（中央实时显示百分比）；QuickJump 快速定位无需快捷键——列表聚焦时**直接键入**即弹出模糊匹配浮层。
:::
